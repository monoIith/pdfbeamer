# Bundled fonts

The application bundles Noto Sans, Noto Serif, and Noto Sans Mono from the
official Noto distribution under the SIL Open Font License 1.1. The matching
`OFL-*.txt` files are shipped with the application.

Source paths:

- `https://cdn.jsdelivr.net/gh/notofonts/notofonts.github.io/fonts/NotoSans/hinted/ttf/`
- `https://cdn.jsdelivr.net/gh/notofonts/notofonts.github.io/fonts/NotoSerif/hinted/ttf/`
- `https://cdn.jsdelivr.net/gh/notofonts/notofonts.github.io/fonts/NotoSansMono/hinted/ttf/`

Noto Sans and Noto Serif include Regular, Bold, Italic, and BoldItalic masters.
Noto Sans Mono officially provides upright Regular and Bold masters; italic and
bold-italic requests use the renderer's synthetic slant.
